# Logo — MAD Shop

Déposez ici votre logo :

| Fichier            | Version conseillée                                  |
|--------------------|-----------------------------------------------------|
| `logo.png`         | Logo **blanc**, fond **transparent**, carré (512×512+) |

C'est la version blanche (celle sur fond noir de vos visuels) qui rend le mieux
sur le fond sombre du site. Dès que le fichier est présent, il remplace
automatiquement le logo typographique de repli, dans le header et le footer.

> Format : PNG transparent (ou SVG converti en PNG). Carré de préférence.
