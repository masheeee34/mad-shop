# Photos produits — MAD Shop

Déposez ici vos vraies photos, en respectant **exactement** ces noms de fichiers.
Tant qu'un fichier est absent, un joli placeholder brandé s'affiche à la place.

Format conseillé : **carré (1:1)**, 1200×1200 px minimum, `.jpg` ou `.webp`.

| `airpods-max-2.jpg`       | AirPods Max — vue 2                       |
